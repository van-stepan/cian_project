# Выгрузка поставок и приёмок ВБ по складам в Удмуртии

Скрипт `wb_udmurtia_export.py` собирает из **официального API Wildberries**
данные по вашим поставкам и приёмкам на склады в Удмуртии (склады ВБ там —
**«Ижевск»** и **«Сарапул»**) и складывает их в Excel + CSV. По желанию
скачивает и сами **документы-акты о приёмке** в PDF/ZIP.

Цель — получить документальное подтверждение того, что у вас были поставки /
товарооборот, связанные с Удмуртской Республикой. Данные берутся **только из
вашего кабинета по вашему API-ключу**. Ничего не досочиняется: что вернёт
API — то и попадёт в файл.

## Что выгружается

1. **Поставки (поступления на склад)** — эндпоинт `/api/v1/supplier/incomes`
   (категория API «Статистика»). По каждой строке: дата поступления, дата
   приёмки (`dateClose`), склад, артикул продавца, баркод, `nmId`, количество,
   сумма, `incomeId`. Отбираются только строки, где склад содержит «Ижевск» /
   «Сарапул» / «Удмурт».
   - Лист **«Поставки (сводка)»** — одна строка на поставку (`incomeId`) со
     списком всех артикулов и общим количеством.
   - Лист **«Поставки (детально)»** — построчно.

2. **Приёмка (платная приёмка)** — эндпоинт
   `/api/v1/analytics/acceptance-report` (категория API «Аналитика»).
   Привязывается к поставкам в Удмуртию по `incomeId`.
   - Лист **«Приёмка (акты)»**.

3. **Документы-акты о приёмке (PDF/ZIP)** — по флагу `--download-acts`, через
   API документов `https://documents-api.wildberries.ru` (категория API
   **«Документы»**): `/documents/list` + `/documents/download`. Файлы
   сохраняются в папку `<out>_acts/`, а их перечень — на лист
   **«Документы (акты)»**.

   ⚠️ **Важно:** список документов ВБ **нельзя отфильтровать по складу** — акты
   выдаются по всему кабинету. Поэтому скрипт скачивает акты приёмки за период,
   а к Удмуртии вы сопоставляете их **по дате / `incomeId`** через лист
   «Поставки». Отбор среди документов — по ключевым словам в названии/категории
   (по умолчанию `приёмк` / `приемк` / `acceptance`) или по точной категории
   (`--doc-category`).

## Подготовка

1. В ЛК продавца: **Настройки → Доступ к API** → создать токен с доступом к
   категориям **«Статистика»**, **«Аналитика»**, а для актов — ещё и
   **«Документы»**.
2. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск

```bash
export WB_API_TOKEN="ваш_токен_из_ЛК"

# поставки + приёмка:
python3 wb_udmurtia_export.py --date-from 2023-01-01 --date-to 2024-12-31

# то же + скачать акты-документы (PDF/ZIP) в папку udmurtia_wb_export_acts/:
python3 wb_udmurtia_export.py --date-from 2023-01-01 --download-acts
```

Полезные служебные режимы (выводят и выходят):

```bash
# посмотреть, какие категории документов есть в кабинете:
python3 wb_udmurtia_export.py --date-from 2023-01-01 --list-doc-categories

# получить список всех документов за период (в CSV), чтобы найти нужную категорию:
python3 wb_udmurtia_export.py --date-from 2023-01-01 --date-to 2024-12-31 --list-docs
```

Параметры:

| Параметр               | Назначение                                                        |
|------------------------|-------------------------------------------------------------------|
| `--date-from`          | начало периода, `ГГГГ-ММ-ДД` (обязательно)                        |
| `--date-to`            | конец периода, `ГГГГ-ММ-ДД` (по умолчанию — сегодня)             |
| `--warehouse СЛОВО`    | ключевое слово склада, можно несколько раз (по умолч. Ижевск/Сарапул/Удмурт) |
| `--out ПРЕФИКС`        | префикс имён выходных файлов (по умолч. `udmurtia_wb_export`)     |
| `--no-acceptance`      | не запрашивать отчёт о платной приёмке                            |
| `--download-acts`      | дополнительно скачать акты-документы (PDF/ZIP) в `<out>_acts/`    |
| `--doc-category ID`    | точная категория документов вместо отбора по словам               |
| `--acts-keyword СЛОВО` | ключевое слово для отбора актов среди документов (можно несколько)|
| `--list-doc-categories`| показать категории документов и выйти                            |
| `--list-docs`          | выгрузить список документов за период в CSV и выйти               |
| `--doc-locale`         | язык категорий документов (`ru`/`en`/`zh`, по умолч. `ru`)        |

## Результат

- `udmurtia_wb_export.xlsx` — листы: сводка, детально, приёмка (+ «Документы
  (акты)» при `--download-acts`);
- `udmurtia_wb_export_postavki_svodka.csv`
- `udmurtia_wb_export_postavki_detail.csv`
- `udmurtia_wb_export_priemka_akty.csv`
- при `--download-acts`: `udmurtia_wb_export_akty_dokumenty.csv` +
  папка `udmurtia_wb_export_acts/` со скачанными PDF/ZIP.

CSV — в кодировке UTF-8 с BOM, чтобы корректно открывались в Excel.

## Замечания

- **Лимиты запросов.** У API ВБ строгие лимиты (у статистики — нередко не чаще
  1 запроса в минуту; у документов — пачками по 5 за 10 c). Скрипт сам делает
  паузы и повторы при ответе `429`/`5xx`.
- **Документы не фильтруются по складу** — см. пункт 3 выше: сопоставление к
  Удмуртии идёт по дате/`incomeId` через лист «Поставки».
- Если за период поступлений по складам Удмуртии не найдено — скрипт честно
  сообщит об этом и оставит листы пустыми.
